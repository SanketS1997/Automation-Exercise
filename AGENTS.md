# AutomationExercise - Agent Instructions

## Project Overview

This is a Playwright + TypeScript test automation framework for the AutomationExercise application.

The framework follows a Hybrid Automation Framework approach using:

- Playwright
- TypeScript
- Page Object Model (POM)
- Component-based architecture
- Locator classes
- Validator classes
- Fixtures
- Test data
- Hooks
- Services
- API automation
- Allure reporting
- Logger utilities

## Application

Base URL: https://automationexercise.com/

## Technology Stack

- Playwright
- TypeScript
- Node.js
- Playwright Test Runner
- Allure
- JSON test data
